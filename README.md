# Weather Data Scraping & Analysis 🌤️

This project demonstrates a Python script that scrapes 7-day weather forecast data from the National Weather Service (NWS) using **BeautifulSoup4** and **Requests**.

### Features:
- Web Scraping to extract temperature, date, and description.
- Data processing and cleaning using **Pandas**.
- Data visualization plotting temperature trends using **Matplotlib**.

### Technologies Used:
- Python
- Pandas
- Matplotlib
- BeautifulSoup
